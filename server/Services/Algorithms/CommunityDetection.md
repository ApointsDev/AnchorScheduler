# 社区发现 (Community Detection)

## 算法简介
社区发现旨在识别网络中联系紧密的节点组（社区）。在时间管理系统中，用于发现用户的日程模式，例如识别哪些任务经常一起出现，或者识别高精力消耗的时间段模式。

## 算法原理
本实现使用 **Louvain 算法**，这是一种基于模块度（Modularity）优化的启发式算法。

算法分为两个阶段，并迭代执行：
1.  **模块度优化（局部移动）**：
    *   初始时，每个节点属于一个独立的社区。
    *   对于每个节点，尝试将其移动到邻居节点的社区中。
    *   计算移动带来的模块度增量（Delta Q）。
    *   如果增量为正且最大，则移动该节点。
    *   重复此过程直到局部最优（没有移动能增加模块度）。
2.  **社区聚合（构建新图）**：
    *   将第一阶段发现的每个社区视为一个新节点。
    *   社区内的边权重转化为新节点的自环权重。
    *   社区间的边权重转化为新节点间的边权重。
    *   构建新的图结构。

重复上述两个阶段，直到图无法进一步聚合或模块度不再增加。

## 时间复杂度
-   **时间复杂度**：O(N log N)（经验值，对于稀疏图）。
-   **空间复杂度**：O(N + E)。

## 使用示例

```typescript
import { CommunityDetectionAlgorithm } from './CommunityDetection';

const algorithm = new CommunityDetectionAlgorithm();

// 1. 准备数据
// 构建图结构，节点为任务，边权重表示关联强度（如时间接近度、类型相似度）
const graph = {
  nodes: new Map([
    ['A', { taskId: 'A', ... }],
    ['B', { taskId: 'B', ... }],
    // ...
  ]),
  edges: [
    { from: 'A', to: 'B', weight: 1 },
    // ...
  ]
};

// 2. 执行算法
const result = algorithm.execute({
  graph,
  resolution: 1.0 // 可选：分辨率参数
});

// 3. 处理结果
console.log(result.communities); // Map { 'A' => 0, 'B' => 0, 'C' => 1 }
console.log(result.modularity); // 0.45
```

## 参数说明
-   `graph`: 输入图结构 (`Graph<TaskNode>`)。
-   `resolution`: 分辨率参数（默认 1.0）。
    *   `> 1.0`: 倾向于发现更小、更紧密的社区。
    *   `< 1.0`: 倾向于发现更大、更松散的社区。
-   `iterations`: 最大迭代次数。

## 适用场景
-   **模式识别**：发现用户的习惯模式（如“周一早晨通常处理邮件和会议”）。
-   **任务分组**：将相关任务自动分组建议。
-   **推荐系统**：基于相似用户的社区进行推荐。

## 限制与注意事项
-   **启发式**：Louvain 算法是启发式的，结果可能依赖于节点的遍历顺序（本实现按索引顺序）。
-   **分辨率限制**：存在分辨率限制问题（Resolution Limit），可能无法检测到非常小的社区（相对于整个网络）。
