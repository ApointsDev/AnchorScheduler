# 🎨 基于 Simple Design System 重绘 UI — 第一步

> 给设计师看的操作指南。
> 不从头画，直接用 Figma 社区里的 **Simple Design System** 改。

---

## 一、先装好 Simple Design System

在 Figma 里操作：

1. 打开 **Figma Community**（底部工具栏或菜单 Plugins → Figma Community）
2. 搜索 **"Simple Design System"**
3. 作者是 **Admiral Studio** 或类似（免费、Star 最多的那个）
4. 点击 **Open in Figma** 或 **Duplicate** 到你自己的 Drafts

这个库已经自带：
- 颜色变量系统（Primitives → Tokens）
- 按钮、输入框、弹窗、开关、徽标等基础组件
- 浅色 / 深色两套主题
- 响应式断点预设

**我们要做的不是重画，而是把它的变量换成我们项目的颜色。**

---

## 二、把 SDS 的颜色改成我们的

SDS 通常用 `primitives` 存色值、`tokens` 做语义化命名。你需要找到它的颜色变量面板，把下面这些覆盖进去。

### 主色（蓝色系）
| 用在哪里 | 色值 |
|----------|------|
| 品牌主色 | `#467EE5` |
| 悬停加深 | `#3765B7` |
| 浅色背景 | `#EEF3FF` |

### 功能色
| 用在哪里 | 色值 |
|----------|------|
| 成功/绿色 | `#10B981` |
| 警告/橙色 | `#F97316` |
| 危险/红色 | `#EF4444` |
| 信息/蓝色 | `#3B82F6` |

### 中性色
| 用在哪里 | 浅色模式 | 深色模式 |
|----------|----------|----------|
| 主文字 | `#1F2937` | `#F9FAFB` |
| 次要文字 | `#4B5568` | `#D1D5DB` |
| 辅助文字 | `#718096` | `#9CA3AF` |
| 页面背景 | `#F7FAFC` | `#111827` |
| 卡片背景 | `#FFFFFF` | `#1F2937` |
| 边框 | `#E2E8F0` | `#374151` |

> 💡 SDS 改了 primitives 色值后，所有组件会自动跟着变。先确认改完颜色后按钮、输入框效果对不对。

## 三、SDS 自带组件清单（直接用，改颜色即可）

这些 SDS 大概率已经提供了，**你只需要确认样式、微调即可**，不用新建：

| 序号 | 组件 | SDS 里叫什么 | 我们需要的样子 |
|------|------|-------------|---------------|
| 1 | 按钮 | Button | 5种样式（主/次要/边框/幽灵/危险），3种尺寸 |
| 2 | 输入框 | Input / Text Input | 带标签 / 不带标签，含错误状态 |
| 3 | 文本域 | Textarea | 高度更高，其他同输入框 |
| 4 | 开关 | Switch / Toggle | 宽44×高24，开=蓝色底 |
| 5 | 徽标 | Badge | 5种颜色（成功/警告/错误/信息/中性） |
| 6 | 弹窗 | Dialog / Modal | 带标题+关闭+底部按钮 |
| 7 | 卡片 | Card | 带标题+内容+可选的底部操作栏 |
| 8 | 加载 | Spinner / Loading | 居中旋转图标 + 文字 |

## 四、SDS 没有的组件（需要你在 SDS 基础上新建）

这些是项目特有的组件，SDS 大概率不提供，但你可以**用 SDS 的基础组件拼出来**：

| 序号 | 组件 | 怎么拼 | 说明 |
|------|------|--------|------|
| 9 | 分段控制器 | SDS Button Group + 选中态高亮 | 桌面端用，2-4个选项排成一行 |
| 10 | 底部标签栏 | SDS Tab Bar 改样式 | 手机端用，毛玻璃底 + 图标 + 文字 |
| 11 | 悬浮按钮 | 一个圆形 SDS Button | 右下角蓝色圆形按钮，直径56px，里面一个 + 号 |
| 12 | 搜索栏 | SDS Input + 图标 | 输入框左边放搜索图标，右边放清除 × |

## 六、Figma 文件怎么组织

```
📁 项目名 — Design System
├── 📄 Cover（封面，写上项目名 + 日期）
├── 📄 Tokens（颜色变量、字号、圆角、阴影）
├── 📄 Components（所有组件放这里）
│   ├── Button
│   ├── Input
│   ├── Modal
│   ├── ...
├── 📄 Templates（后续用组件拼页面示例）
```

组件命名示例：`Button / Primary / Medium / Default`

---

## 七、注意这几点

1. **深色模式最后做**。浅色确认没问题了，SDS 切到深色，微调几个颜色变量就行。
2. **手机端和桌面端**是两套布局，有些组件（比如弹窗）在手机上可能要全屏显示。
3. 我们的图标库是 **Lucide**，Figma 有 Lucide 插件可以直接搜图标拖进来。
4. 不确定的地方**截图问我**，别猜。尤其是 SDS 里命名跟我们文档对不上的情况。
